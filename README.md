
# Healthcare Data Remediation & Integration Pipeline

## Overview
An end-to-end data remediation and integration pipeline designed to process, validate, 
and transform healthcare datasets across Salesforce and SAP integrated systems. 
Ensures data accuracy, consistency, and readiness for advanced analytics and operational reporting.

## Tech Stack
- **Language:** Python, SQL
- **Cloud:** AWS (S3, Glue, Lambda)
- **Integration:** Salesforce, SAP
- **Documentation:** Visio, Excel
- **BI:** Tableau, Power BI
